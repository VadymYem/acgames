# AuthorChe Games

Сховище ігор для каталогу [authorche.top/games](https://authorche.top/games/).

Публічний runtime опубліковано на [GitHub Pages](https://vadymyem.github.io/acgames/). Після перенесення репозиторію використовується адреса `VadymYem/acgames`. GitHub Actions збирає та публікує лише каталог `dist`; сирий checkout не є готовим runtime. Налаштування приватності репозиторіїв не змінюються автоматично.

## Реєстр і перевірка

`catalog.json` містить унікальні ідентифікатори, локальні обкладинки, точки входу та окрему підтримку ПК, Android й iOS. `candidateDevices` описує пристрої для повторних тестів; `devices` після перегляду звітів дозволяє показувати гру лише там, де її запуск пройшов перевірку. Файли проблемних ігор зберігаються для ремонту. Звичайна збірка не копіює до публічного runtime ігри без жодного успішного пристрою.

`excluded` пояснює виключення дублікатів, порожніх завантажувачів, неповних runtime та інших записів, які не є окремими доступними іграми. Ліцензії та відомості про первинних авторів зберігаються.

## Локальна збірка

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm run audit
npm run syntax
npm test
python3 tests/sanitize.test.py
python3 -m http.server 4173 --directory dist
```

Сирий checkout не є готовою збіркою: `tools/build.py` додає локальні залежності та Ruffle. Продакшн не повинен завантажувати бібліотеки з CDN.

## Браузерна перевірка

GitHub Actions запускає Chromium для ПК й Android та WebKit для iOS. Це емуляція браузерів, а не тест на фізичних телефонах. Перевіряються завантаження, базовий ввід, помилки JavaScript, відсутні ресурси та зовнішні мережеві запити. Успішний smoke test не означає проходження всіх рівнів або перевірку кожної ігрової механіки.

Для приватної діагностики кандидатів спочатку виконайте `npm run build:review`, після встановлення Playwright:

```sh
GAME_DEVICE=desktop node tests/browser.mjs
GAME_DEVICE=android node tests/browser.mjs
GAME_DEVICE=ios node tests/browser.mjs
```

`GAME_IDS` обмежує діагностичний запуск списком ID через кому. Повні звіти зберігаються в `reports/browser/<device>/results.json` і в артефактах GitHub Actions. Невдалий запуск опублікованої гри завершує перевірку помилкою; проблемні кандидати залишаються у звіті для ремонту.

`tools/review.py` застосовує лише повний комплект звітів трьох пристроїв і записує SHA перевіреного коду та ID workflow. Після перевірки оновлений реєстр і обкладинки переносяться у репозиторій `VadymYem/a`, а `tools/build-games.py` в ньому генерує каталог.

## Приватність

Сторонні рекламні SDK замінені локальними обробниками необхідних callback. CSP обмежує мережеві ресурси локальним runtime. Аналітика сайту працює у батьківській сторінці AuthorChe після згоди користувача; ігри не повинні самостійно підключати аналітику.

## Ліцензії

Код каталогу й кожна гра мають власні умови використання. Дивіться `LICENSE` та ліцензійні файли всередині папок ігор. Назви ігор і відомості про їхніх авторів не замінюються авторством AuthorChe.

## Перевірка плеєра на основному сайті

Workflow `Verify published games` відкриває кожну дозволену для пристрою гру з опублікованого GitHub Pages runtime у cross-origin iframe. Локальна тестова сторінка запускається лише всередині GitHub Actions і має ті самі sandbox-дозволи, що й основний плеєр. Перевіряються запуск, ввід, стан iframe, JavaScript, відсутні файли та зовнішні запити. Поле `game_ids` у ручному запуску обмежує перевірку вибраними ID. Режим `website` додатково відкриває справжню сторінку `authorche.top`; захист цього домену може блокувати датацентрові адреси GitHub Actions. Такий блок записується окремо, а перевірка припиняється без повторних спроб. Статус sandbox-перевірки не підміняє результат перевірки захищеного домену.

Workflow `Publish AuthorChe Games` спочатку виконує збірку, статичний аудит, синтаксичні та регресійні тести. Підготовка збірки вимикає клієнт сервера розробки Friendly Fire, виправляє передавання текстур Subway Surfers, показує локальну SVG-інструкцію BreakLock як зображення й прибирає службовий callback itch.io та зовнішнє фонове радіо ayuncraft. Ліцензії і відомості про первинних авторів збережені.
