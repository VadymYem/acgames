# 🎮 AC-Games

**AC-Games** — відкрита колекція браузерних ігор, які запускаються прямо у браузері без жодного завантаження або встановлення.

## 📦 Структура репозиторію

```
acgames/
├── games/                    # Папка з усіма іграми
│   ├── agario-offline/       # Кожна гра — окрема папка
│   ├── slitherio-offline/
│   ├── slope/
│   ├── minecraft/
│   └── ...                   # ~185 ігор
├── index.html                # Каталог ігор (GitHub Pages)

```

## 🎯 Можливості

- ✅ **~185 ігор** — аркади, стратегії, головоломки, екшн
- ✅ **Без реклами** — всі сторонні рекламні SDK видалені
- ✅ **Мобільні** — адаптивний інтерфейс для смартфонів та планшетів
- ✅ **Фільтрація за пристроєм** — ігри відфільтровуються для ПК або мобільних
- ✅ **Без встановлення** — відкриваєш і граєш
- ✅ **Відкритий код** — можеш форкнути та розгорнути у себе

## 🚀 Локальний запуск

```bash
git clone https://github.com/VadymYem/acgames.git
cd acgames

# За допомогою Python
python3 -m http.server 8080

# Або Node.js
npx serve .
```

Відкрий в браузері: `http://localhost:8080`
