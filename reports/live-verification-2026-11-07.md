# AuthorChe Games — перевірка публікації 7 листопада 2026

## Поточний стан

Репозиторії перенесені з `agpgp` до `VadymYem`: основний сайт — `VadymYem/a`, ігри — `VadymYem/acgames`. Основний репозиторій приватний; репозиторій ігор уже публічний. Під час цієї роботи приватність не змінювалася.

- Каталог: https://authorche.top/games/
- Runtime ігор: https://vadymyem.github.io/acgames/
- 184 унікальні кандидати; 152 опубліковані гри, 76 дозволені на Android і 71 на iOS.
- 32 непідтверджені кандидати приховані; їхні вихідні файли збережені.

Цей звіт замінює застарілі відомості про відсутність публікації в попередньому `docs/games-audit-2026-11-07.md` основного репозиторію. Новий хостинг поза GitHub та вхід у Cloudflare не використовувалися. Наявна публікація основного сайту залишається чинною; runtime ігор публікує GitHub Actions у GitHub Pages.

## Виправлення після публікації

1. Каталог і плеєр використовують адресу після перенесення репозиторію. Публікується підготовлений `dist`, а не сирий checkout.
2. Маніфест містить `buildRevision`; HTML, стилі й скрипти версіоновані, щоб відвідувачі не отримували старі SDK після оновлення.
3. Drive Mad більше не підключає обфускований GameMonetize-завантажувач. Локальні GD callback працюють також за пізньої ініціалізації гри.
4. Вилучені клієнт сервера розробки Friendly Fire, callback itch.io у We Become What We Behold та зовнішнє фонове радіо ayuncraft.
5. Subway Surfers отримує правильну текстуру після асинхронного завантаження моделей; локальний адаптер не звертається до чужого `parent` у cross-origin iframe.
6. BreakLock показує локальну SVG-інструкцію без забороненого `object`.
7. Vex 3 отримує Promise-відповідь локального рекламного API; Raygun-завантажувач, його обробники й невикористаний трекер вилучаються зі збірки.
8. Вбудовані застарілі Flash-трекери та необов’язковий Kongregate API отримують локальну відповідь без мережевого запиту. Це перевіряє регресійний тест.
9. Якщо браузер не має WebGL, плеєр показує конкретне пояснення замість порожнього екрана або нескінченного завантаження.
10. Поле 2048 підлаштовується до ширини та висоти iframe; усі 16 клітинок, рахунок і кнопка нової гри поміщаються у перевіреному настільному плеєрі. Рух плиток і нарахування очок перевірені вручну на основному сайті.

Додані раніше Connect Four, Sudoku, Nonogram і Simon Memory збережені. Нових копій наявних ігор не створено. Відомості про первинних авторів і ліцензії збережені.

## Межі перевірки

Chromium перевіряє ПК та емуляцію Android; WebKit — емуляцію iOS. Перевіряються завантаження, базовий ввід, ігрова поверхня, стан iframe, помилки JavaScript, відсутні файли та зовнішні мережеві запити. Це не проходження всіх рівнів і не перевірка на фізичних телефонах.

У `Verify published games` режим `sandbox` відкриває справжні опубліковані файли GitHub Pages у cross-origin iframe з тими самими sandbox-дозволами, що й основний плеєр. Тестова батьківська сторінка працює лише всередині GitHub Actions на localhost і не є іншим публічним хостингом. Режим `website` перевіряє сам `authorche.top`.

Повний контроль останньої опублікованої збірки: https://github.com/VadymYem/acgames/actions/runs/42418164370 . Android — 76/76, iOS — 71/71; помилок JavaScript, відсутніх ресурсів та зовнішніх відповідей у цих сценаріях немає. ПК — 148/152: виявлені звернення Burger Run та SM64 до недоступного cross-origin parent; Audio Game й Jetpack Joyride отримали HTTP 503 під час завантаження ресурсів. Це справжній невдалий прогін; він не позначається успішним заднім числом.

Перевірка основного сайту, включно зі статичними сторінками віршів, cookies і браузерними сценаріями, успішна: https://github.com/VadymYem/a/actions/runs/42415956742 . Видалений користувачем повторний список віршів не відновлювався; тест перевіряє справжні статичні посилання поза скриптами.

Справжній основний домен у прогоні https://github.com/VadymYem/acgames/actions/runs/42416235261 : Android 7/7, iOS 6/7; Subway Surfers на iOS завершив очікування навігації iframe за тайм-аутом. Настільний GitHub Actions отримав захисну сторінку Cloudflare до запуску ігор. Це обмеження датацентрового клієнта; воно не доводить несправності ігор. Захист не послаблювався й не обходився. Успішний sandbox-прогін не підміняє цей результат.

## Cookies та SEO

Компактний банер зберігає прийняття або відмову на 180 днів; вибір можна змінити з футера. Авторська аналітика потребує згоди. CSP основного сайту блокує виконання автоматично доданого Cloudflare Insights; сам вставлений тег може залишатися в HTML. У перевірених адресних Android-сценаріях після оновлення CSP зовнішніх відповідей не було.

Збережені SEO-метадані, canonical, sitemap, структуровані дані, географічний контекст Bonn / Sankt Augustin / Черкаси та 67 статичних сторінок віршів. Статичний аудит охоплює 137 HTML-сторінок, 124 індексовані сторінки й 124 унікальні адреси sitemap. Остання зафіксована оцінка SEObility — 89%; нової оцінки 100% і конкретних позицій пошуку не підтверджено.

Окреме обмеження ручного браузера: у цьому віддаленому середовищі WebGL недоступний. Ruffle також повідомляє про непідтриманий `BitmapData.draw` у резервному рендерері. У Bloons TD 4 підтверджені меню, перший раунд і розміщення вежі, але це не підтвердження всіх механік емуляції. У консолі Ruffle залишається нефатальна помилка застарілого Kongregate `services`; мережевий запит до нього локалізовано. У Vex 3 ручний запуск у цьому середовищі залишився на Loading; CI з програмним графічним рендерером після розширення тесту натискає PLAY та показує подальшу ігрову анімацію. Повний ручний ігровий сценарій Vex 3 не підтверджено.

Не відновлені до публікації такі 32 кандидати:

`adarkroom`, `basketballstars`, `basketbros`, `bobtherobber2`, `bp`, `breakout`, `coloron`, `crossyroad`, `cuttheropeholiday`, `cuttheropetimetravel`, `dogeminer`, `drift-boss`, `fireboy-and-watergirl-1`, `fireboy-and-watergirl-2`, `fireboy-and-watergirl-3`, `fireboy-and-watergirl-4`, `geometry`, `konnekt`, `motox3m`, `paperio`, `pingpoing`, `poker`, `sandbox`, `slope3`, `stacktower`, `subway-surfers`, `timeshooter1`, `tube-jumpers`, `tunnelrush`, `vex5`, `weavesilk`, `wordle`.

Серед зафіксованих причин: відсутні ресурси або рушії, зовнішні залежності, помилки початкового коду, непідтверджена інтерактивна поверхня. Окремі причини кожного запису зберігає попередній повний аудит у репозиторії сайту. Повернення до каталогу вимагає ремонту та повторного тестування відповідного пристрою.

Порожні проксі-сторінки й дублікати залишаються виключеними за `catalog.json.excluded`. Cookie Clicker не публікується через наявну в джерелах заборону повторного розміщення. Повне завершення ремонту всіх початкових ігор не заявляється.
